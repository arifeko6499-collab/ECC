# Animal Habitat Adventure Mobile App

This folder contains a mobile-friendly Progressive Web App (PWA) version of the game.

## Run locally

```bash
cd /workspaces/ECC/examples/animal-habitat-game
python3 -m http.server 8000
```

Then open http://127.0.0.1:8000/index.html.

## Install on mobile

- Open the page in Chrome or Safari on a phone.
- Use the browser's "Add to Home Screen" or "Install App" option.
- Launch it from the home screen like a native app.

## Build for app stores

For production app-store distribution, wrap this PWA in Capacitor or TWA and publish through the relevant stores.
